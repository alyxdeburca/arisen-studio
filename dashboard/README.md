# Arisen Studio Migration Dashboard

Static, self-contained progress dashboard tracking the migration of Arisen Studio from Windows DevExpress WinForms to Linux on Mono using stock `System.Windows.Forms`.

> **Proposal notice:** The full-completion definition and milestones beyond `M1b` shown on the dashboard are proposed estimates and have **not** been approved by the project owner.

## Files

- `milestones.json`: Hand-edited milestone statuses, evidence lines, `port_map`, M7/M8 tracking details, and manual extensibility gate facts.
- `measure.py`: Read-only analyzer for `~/github.com/ohhsodead/arisen-studio`. Validates baseline repository counts, computes Dimensions A/B/C and Overall codebase percentages, checks computed extensibility gates, and generates `index.html`.
- `index.html`: Self-contained static dashboard generated by `measure.py` (inline CSS, inline JS, embedded JSON data; zero network requests). **Never hand-edit `index.html`.**
- `server.py`: Background stdlib HTTP server serving `index.html` and exposing the completion API on `127.0.0.1:8787`.
- `events.json` / `server.pid` / `server.log`: Persisted completion notifications, server PID, and HTTP server log (created at runtime).
- `README.md`: Update and usage instructions.

## Background Server & Completion API

Start the dashboard server (defaults to `127.0.0.1:8787`):
```bash
python3 -I server.py --host 127.0.0.1 --port 8787
```

Dashboard URL: `http://127.0.0.1:8787/`

### Endpoints

- `GET /` (or `GET /index.html`): Serves `index.html`.
- `GET /api/health`: Returns `{"ok": true, "pid": ..., "host": ..., "port": ..., "uptime_seconds": ...}`.
- `GET /api/status` (alias `GET /api/data`): Returns the current measured JSON payload from `index.html`.
- `GET /api/events`: Returns recorded work-completed notifications from `events.json`.
- `POST /api/complete` (alias `POST /api/work-completed`): Notifies the server that work has finished, optionally updates `milestones.json`, appends an event to `events.json`, re-runs `python3 -I measure.py`, and returns updated percentages (rolls back on `measure.py` failure).
  - Empty body `{}` triggers a re-measure + notification event.
  - Optional JSON fields: `dry_run` (bool), `source` (str), `summary` / `message` (str), `milestone_id` + `status` / `approved` / `approval_note` / `manual_percent` / `evidence` / `append_evidence`, `port_map_add` (`[{"old": ..., "new": ...}]`), `resolve_modules`, `checklist_updates`, `gate_updates`.
- `POST /api/refresh`: Re-runs `python3 -I measure.py` without editing `milestones.json`.

### Main-Thread `curl` Examples

Simple completion notification and re-measure:
```bash
curl -sS -X POST http://127.0.0.1:8787/api/complete \
  -H 'Content-Type: application/json' \
  -d '{"source":"main-thread","summary":"Completed slice build and smoke test"}'
```

Update a milestone, add a `port_map` entry, and regenerate `index.html`:
```bash
curl -sS -X POST http://127.0.0.1:8787/api/complete \
  -H 'Content-Type: application/json' \
  -d '{
    "source": "main-thread",
    "summary": "Ported ReportIssueDialog",
    "milestone_id": "M2",
    "status": "done",
    "approved": true,
    "manual_percent": 100,
    "port_map_add": [
      {"old": "Forms/Dialogs/ReportIssueDialog.Designer.cs", "new": "Forms/Dialogs/ReportIssueDialog.cs"}
    ]
  }'
```

## How to Update

1. **Edit `milestones.json`** when progress or decisions change:
   - Update milestone `status`, `approved`, `approval_note`, or `evidence`.
   - Record ported Dimension B (UI-coupled) or Dimension C (layout designer) files in `port_map` as objects with exact relative paths:
     ```json
     "port_map": [
       {
         "old": "Forms/Dialogs/ReportIssueDialog.Designer.cs",
         "new": "Forms/Dialogs/ReportIssueDialog.cs"
       }
     ]
     ```
     An entry counts **only** when the `new` file exists under `src/Arisen Studio Mono/` and `old` matches an exact relative path under `src/Arisen Studio/` (files are never matched by basename).
   - Update M7 module resolution flags, M8 packaging checklist states, or `manual_gates` as facts change.
2. **Regenerate `index.html`** using isolated Python mode from inside this folder:
   ```bash
   python3 -I measure.py
   ```
3. **Open `index.html`** directly in a web browser (light/dark themes adapt automatically via `prefers-color-scheme`; layout supports 360px to 1000px viewports).

## Computed vs. Manual Figures

- **Computed automatically by `measure.py`**:
  - Line counts (`wc -l` newline semantics) and file counts across `Arisen Studio.csproj` (165 items: 54 layout designers, 3 excluded `Properties/*.cs`, 42 UI-free, 66 UI-coupled) and `Arisen Studio Mono.csproj` (24 linked UI-free files).
  - Dimension A, Dimension B, Dimension C, Overall percentage, M4 (other layouts excluding `MainWindow.Designer.cs` and `ReportIssueDialog.Designer.cs`), M5 (`MainWindow.Designer.cs` alone), and M6 (Dimension B). All percentages are **floor-truncated** to 1 decimal place (never rounded up).
  - Gate check for hard-coded Windows backslash paths or `"Segoe UI"` across `src/Arisen Studio Mono/` own `.cs` files.
  - Gate check for `../scripts/check-cross.sh` and `../scripts/check-elf.sh` relative to `measure.py`.
- **Manual (from `milestones.json`)**:
  - Milestone statuses (`done`, `proposed`, `planned`), approval labels, evidence notes, M7 Windows-only module decisions (`0 of 5`), M8 packaging checklist items, and manual extensibility gates (`shared_control_layer`, `layout_uses_containers`, `self_contained_elf`).
